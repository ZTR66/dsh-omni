# dsh-omni 宣传视频 · 拍摄参考

给想要做这支视频的人：这不是逐字稿，是一份可以直接照着执行的方案。
分镜、素材、台词、技术标注都在里面，你可以改台词，但建议保留结构和节奏。

---

## 一、先定调

### 这支视频要证明什么

**一句话**：一个插件让 AI 真正能"看"视频、"听"音频、"画"图，而且它知道自己什么时候不该用 AI 生成。

三个必须让观众记住的点，按重要性排序：

1. **丢进去一个没看过的视频，它能讲出内容** —— 这是最有冲击力的演示，放开头
2. **采样密度由 AI 自己决定** —— 区别于那些"固定截 9 帧"的方案
3. **它会拒绝** —— 代码能画的东西，它拒绝调用生成模型，这是全片最有态度的部分

### 时长与节奏

**目标 4 分钟**（B 站技术类完播率甜蜜点在 3–5 分钟）

| 段落 | 时长 | 作用 |
|---|---|---|
| 钩子 | 12 秒 | 决定 70% 的人留不留 |
| 痛点 | 20 秒 | 建立"这问题真实存在" |
| 演示主体 | 2 分 10 秒 | 三个能力，一个比一个深 |
| 技术底牌 | 40 秒 | 建立可信度，区分于搬运号 |
| 收尾 | 30 秒 | 安装方式，不留悬念 |

### 观众是谁

**DSH 用户 + 对 AI 工具敏感的开发者**。他们见过太多"套壳 GPT"的插件，所以：

- 不要吹"全能"
- 要展示**具体的数字**和**具体的拒绝**
- 说清楚"这解决了我什么麻烦"，而不是"我做了个很厉害的东西"

## 二、封面与标题

### 标题候选

按点击率排序：

1. `我给 AI 装上了眼睛和耳朵，然后它拒绝了我`
2. `AI 也能看视频了，而且它会自己决定看多细`
3. `一个插件，让 AI 看视频、听音乐、画图、生成视频`

**推荐第 1 个**。它制造了一个反常识的悬念（"拒绝"），而且承诺了反转。

### 封面

**画面**：左侧一张 70 格宫格图（带时间码），右侧一个对话框气泡，里面写着「第 24 秒发生了什么？」，键盘上放着一个视频文件图标。

**文字**（大字，压在图上）：

```
它真的看懂了
```

**关键**：宫格图必须能看清时间码，这是"它真的在逐帧看"的视觉证据。

## 三、分镜脚本

### 段落 0 · 钩子（0:00–0:12）

| 项 | 内容 |
|---|---|
| **画面** | 屏幕录制。把 `Fable 5.5` 那个 B 站视频拖进对话框，只打一行字：「这个视频讲了什么」。**不要**先解释任何东西。 |
| **节奏** | 前 3 秒必须已经出现"拖文件"这个动作。不要放片头 LOGO。 |
| **台词** | 「这个视频 82 秒，AI 从来没看过。我没告诉它任何东西，只丢了个文件。」 |
| **技术标注** | 这是真实演示。文件是 B 站 `BV1bpWJ6aExX`，UP 主 `-Morrigan-`，标题「吓哭力孩子们，fable 5.5 纯代码搓出来的动画」。 |

**紧接着（8–12 秒）**

画面切到 AI 的回答，用**滚动+局部放大**处理，让观众看清它在说「海边小镇」「橙色方块角色」「陨石」「驾驶机器人冲上天」。

台词：「它把整条故事线讲出来了。」

> **剪辑要点**：这里不要配激昂 BGM。安静，让观众自己意识到"哦它真的看懂了"。

### 段落 1 · 痛点（0:12–0:32）

| 项 | 内容 |
|---|---|
| **画面** | 一个示意图动画：视频文件 → 一个红色叉 → AI 大脑。然后出现文字「多模态消息只支持 text 和 image」。 |
| **台词** | 「原因是硬限制。DSH 的消息模型里，模态只定义了文字和图片两种。视频和音频根本没有位置。」 |
| | 「所以所有号称"AI 看视频"的方案，本质都是同一件事：把视频变成图片。」 |
| | 「区别只在于——怎么变。」 |

**技术标注**（可信度来源，屏幕可打小字）：

```ts
type ModelModalityMap = {
  text: 'text'
  image: 'image'
}
```

> **剪辑要点**：这段要快。观众不需要理解代码，只需要知道"这不是偷懒，是真的有限制"。

### 段落 2 · 三层看法（0:32–1:22）

这是全片的**核心演示**，也最需要设计镜头。

#### 2.1 第一层：概览（0:32–0:52）

| 项 | 内容 |
|---|---|
| **画面** | 屏幕录制，调 `video_scan`，参数 `fps=2, cellWidth=240`。**慢放**渲染过程（实际 1 秒，慢放到 3 秒），让观众看到 70 张缩略图逐格铺满。 |
| **关键** | 宫格出现后，**镜头缓慢推近**，聚焦到左上角时间码 `00:00:00.000`，再平移到右下角 `00:01:21.000`。 |
| **台词** | 「它把 82 秒切成了 70 格，每格带时间码。一格半秒。」 |
| | 「这是一次概览，用来看结构——哪里换镜头，哪里出字幕。」 |

**必须出现的数字**（屏幕角标）：

```
70 格 · 9×8 · 每格 0.5 秒 · 251 KB · 渲染 1.1 秒
```

#### 2.2 第二层：局部细看（0:52–1:08）

| 项 | 内容 |
|---|---|
| **画面** | 紧接着调第二次，参数 `from=27, to=40, fps=5, cellWidth=480`。画面切成左右对比：左边是刚才的概览，右边是这段密集采样。 |
| **台词** | 「看完概览，它自己决定：27 到 40 秒这段值得细看，用 5 帧每秒重新扫一遍。」 |
| **关键** | 强调「**它自己决定**」。这里要停顿一下，让这句话落地。 |

**对比数字**：

```
第一遍  2 fps × 240 px
第二遍  5 fps × 480 px  ← 密度提升 2.5 倍，宽度翻倍
```

#### 2.3 第三层：单帧（1:08–1:22）

| 项 | 内容 |
|---|---|
| **画面** | 调 `video_frames at=26.5 width=1280`。一张全分辨率帧淡入，然后**从整帧推近到一个局部**，让观众看清画面里的文字。 |
| **台词** | 「再往下，抽单帧，原分辨率。宫格看不清的字，这里能读。」 |

> **剪辑要点**：三层要放在**同一个连续屏幕录制**里，不要剪开。观众要看到"同一次对话里，它自己一层层往下看"，这是和"手动截 9 帧"的本质区别。

### 段落 3 · 听（1:22–1:52）

| 项 | 内容 |
|---|---|
| **画面** | 一个音乐文件（推荐用有明显鼓点和调性的）。先放 3 秒音频，同时频谱图动画跑起来。然后调 `audio_analyze`，结果以卡片形式弹出。 |
| **台词** | 「音频这边，它给的不是形容词，是数字。」 |

**必须展示的真实输出**（这是实测数据，来自一个合成的 C 大三和弦 + 120 BPM 鼓点）：

```
BPM        117.45
规律性      0.977        ← 1.0 是完全等距
估计调性    C major      ← 合成的是 C-E-G，判对了
频谱质心    1562.5 Hz
过零率      0.0779
```

| 项 | 内容 |
|---|---|
| **台词** | 「117 拍，C 大调。你可以拿这些数字去配画面，而不是靠'感觉差不多'。」 |
| **反转点** | 「但环境声、人声、自由节奏的曲子，它会直接告诉你——没检测到节拍。而不是硬编一个 0 BPM 出来。」 |

**技术标注**（屏幕小字）：

```
tempo.detected: false  ← 这是一个真实答案，不是失败
```

> **剪辑要点**：这个"它承认自己不知道"的细节，比任何吹嘘都更能建立信任。给它 3 秒静默。

### 段落 4 · 它会拒绝（1:52–2:42）

**这是全片最有态度的部分，也是和"套壳插件"的分水岭。**

#### 4.1 抛出问题（1:52–2:05）

| 项 | 内容 |
|---|---|
| **画面** | 一个分镜表（文字动画逐行出现）：十个镜头，标题、柱状图、转场、logo 动画…… |
| **台词** | 「现在生视频。我让它做一支 60 秒的片子，十个镜头。」 |
| | 「按理说，直接全丢给生成模型最省事。但那样会花多少钱？」 |

**屏幕打出成本对比**（大字，停留 4 秒）：

```
全 AI 生成    12 段 × ¥2.10  ≈  ¥25.20
代码渲染                        ¥0
```

#### 4.2 演示拒绝（2:05–2:25）

| 项 | 内容 |
|---|---|
| **画面** | 屏幕录制，调 `video_generate`，prompt 写「标题页，纯文字排版」。**结果立刻返回拒绝**。 |
| **关键** | 拒绝信息要**放大定格 3 秒**，让观众读完。 |

真实返回内容：

```
# 已拒绝：这些场景代码就能画

- **标题页，纯文字排版**
  「标题页，纯文字排版」代码就能画：文字与排版用 drawtext 或 SVG 渲染，精确可控
  → 改用 image_generate（静态）或 video_compose（序列），成本为 0
```

| 项 | 内容 |
|---|---|
| **台词** | 「它拒绝了。标题页这种东西，代码画得又快又准，为什么要花钱让 AI 猜？」 |
| | 「注意它的判定标准——不是看这个镜头占多少比例。占 2% 还是 80%，能画就是能画。」 |

#### 4.3 两道闸门（2:25–2:42）

| 项 | 内容 |
|---|---|
| **画面** | 示意图动画。两扇门依次出现。 |
| **台词** | 「第一道：能力判定。代码能画的一律拦下。」 |
| | 「第二道：要授权。真需要生成的镜头，得你点头。」 |

**关键台词**（放慢，这是价值观输出）：

> 「而且如果你的环境里根本没有审批服务，它的选择是——不花钱。」

```
approval: unavailable  →  拒绝执行
```

| 项 | 内容 |
|---|---|
| **台词** | 「无人值守的环境，不该自己决定花钱。」 |

> **剪辑要点**：这段可以配一点紧张的 BGM，在"不花钱"三个字时停掉，留白。

## 五、制作注意事项

### 录制

- **终端字号调到 18–20px**，B 站手机端观看占多数
- **深色主题**，截图和录屏都更清楚
- 操作节奏放慢 30%，观众需要时间看清参数和结果
- 不要在录制中切换窗口，容易失焦

### 剪辑

- **前 12 秒不要有任何片头、LOGO、BGM 渐入**
- 宫格图出现时，给 2 秒静止让观众看清
- 数字（70 格、117.45 BPM、¥25.20）**用大字角标**，不要只靠台词
- 拒绝信息、乱码对比这类"证据型画面"，**定格 3 秒以上**

### BGM

- 段落 0–1：**无 BGM**，或极轻的环境音
- 段落 2–3：轻快的电子，音量 -20dB
- 段落 4：紧张感渐强，在"不花钱"处**骤停**
- 段落 5–6：回到中性，收尾用温暖的钢琴

### 弹幕互动点（可选）

在三个位置埋钩子，涨互动：

1. 钩子结尾：「你猜它说了什么？」（停顿，让弹幕猜）
2. 段落 4 拒绝那里：「换成你，会花这 25 块吗？」
3. 收尾：「你希望它下一步支持什么？」

> 关键不是它全能，而是它知道什么时候不该用 AI。
